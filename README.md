# SmartWash — как устроена мойка изнутри

Статический сайт об инженерных сетях мойки самообслуживания SmartWash на 8 боксов (Актобе, Макаренко 5А).

## Что на сайте

- **Схема сетей** — полноэкранный интерактивный изометрический разрез здания: вода, осмос, канализация и очистные, тепло и газ, электрика, воздух. Можно выбрать систему, приблизить бокс, техпомещение, фундамент или очистные, подсветить номера позиций. Масштаб кнопками, Ctrl + колесо или двумя пальцами, перетаскивание, режим «на весь экран».
- **Слои схемы** — переключатель «Низ: под полом» (фундамент, пирог пола, приямки 2 × 2 × 2 м, коллектор, очистные, септики, скважина) и «Верх: боксы и машины» (оборудование, машины заезжают с улицы, светофор горит красным, пена и мойка, выезд).
- **Описание систем** и **цифры для проектировщика** (расходы, стоки, мощности).
- Светлая и тёмная тема (переключатель в шапке, по умолчанию — как в системе), адаптивная вёрстка под телефон, учёт `prefers-reduced-motion`.

## Структура

```
index.html            страница со схемой и текстами
assets/site.css       шапка, навигация, подвал
assets/site.js        тема, подсветка разделов
assets/scheme.js      схема: системы, слои, виды, масштаб, на весь экран
tools/add_pits.py     генератор приямков на схеме
tools/add_layers.py   разметка слоёв и машины
```

Сборки нет — откройте `index.html` в браузере.

## Публикация

Workflow `.github/workflows/pages.yml` публикует сайт на GitHub Pages при пуше в `main`.
Один раз включите: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

> Толщины слоёв и решения по фундаменту — типовые, их уточняет раздел КЖ проекта.
